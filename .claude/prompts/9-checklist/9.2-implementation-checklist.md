## Reality check
This pack is more than a single engineer can execute perfectly on first pass. Skip nothing but
scope everything down first: build the smallest working version of each item, then expand once
it's provably wired up end to end. The measure of progress is not "how many prompts have I run"
but "how many bytes of user-visible functionality survive a full deploy + smoke test."

## Definition of done — for any prompt
- Code merged through PR with review + green checks.
- Tests at the appropriate layer (unit + integration; E2E if user-visible).
- CFN artefacts cfn-lint + cfn-nag clean.
- New endpoints in openapi.yaml + Spectral clean.
- New states mapped in PlatformStatus (type-safe).
- Observability: structured logs with trace_id + request_id; ≥1 metric per new flow; a span for
  the operation.
- Audit log entry for every state-changing action.
- ADR filed if an architectural decision was made. Runbook added/updated if an alert was added.
- Dashboard panel/query added if a new SLI was introduced.
