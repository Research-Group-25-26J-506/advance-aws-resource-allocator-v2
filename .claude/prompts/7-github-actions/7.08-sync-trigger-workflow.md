# Prompt: Templates Sync Trigger Workflow

## Goal
In the platform-templates repo, produce `.github/workflows/sync-trigger.yaml` that calls the
platform's sync API.

## Constraints
- Triggers: workflow_dispatch (manual, env input); nightly schedule (DRY_RUN only, alert on
  unexpected diffs); push to main after tag.
- OIDC assume gh-templates-sync-role in the platform account.
- Job: mint a short-lived token for a system principal, POST /api/v1/admin/templates/sync with
  mode=APPLY (or DRY_RUN per trigger). Poll GET /sync/{id} until terminal.
- Summary to Slack + PR/tag comment. Nightly dry-run failure files a GitHub issue on unexpected
  changes.

## Acceptance
Tagging v1.2.0 triggers a sync to STG. Manual dispatch to PROD requires environment approval.

## Enhancements (v2.1)
- The system principal is the `system-sync` client-credentials client (6.5) with a `sync:trigger`
  scope — never a shared human account; the API authorizes the scope, not a group.
- The sync request pins `commit_sha: ${{ github.sha }}` explicitly — the workflow syncs the commit
  that triggered it, not whatever HEAD is by the time the worker runs.
- Poll loop has a hard timeout (20 min) and surfaces the sync's structured failure report into the
  Actions summary.
