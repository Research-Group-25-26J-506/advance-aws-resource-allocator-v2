# Prompt: GitHub Environments

## Goal
Configure environments platform-dev, platform-stg, platform-prod with protection rules and secrets.

## Constraints
- platform-dev: no protection; auto-deploy from main.
- platform-stg: required reviewers = platform-team; branches limited to main.
- platform-prod: 2 required reviewers from platform-leads; main tagged commits only;
  wait-timer 15 min.
- Environment secrets: AWS_ACCOUNT_ID, AWS_REGION, ROLE_ARN, GRAFANA_URL, SLACK_WEBHOOK_URL,
  PAGERDUTY_INTEGRATION_KEY. Environment variables: PLATFORM_ENV, LOG_LEVEL, FEATURE_FLAGS.
- Repo secrets: SNYK_TOKEN, DEPENDABOT_PAT.
- Rotation cadence documented: 90d tokens, quarterly AWS trust review.

## Acceptance
Prod deploy triggers the approval prompt for the two required reviewers.

## Enhancements (v2.1)
- Environments configured as code (script/Terraform) alongside 7.1's protection-as-code.
- AWS_ACCOUNT_ID / ROLE_ARN are *variables*, not secrets — they aren't sensitive, and hiding them
  makes debugging trust-policy mismatches miserable; keep only genuinely secret values secret.
- DEPENDABOT_PAT replaced by a GitHub App token minted in-workflow where possible — standing PATs
  are the thing OIDC was adopted to kill.
