# Prompt: Build & Push Images

## Goal
Produce `.github/workflows/build-images.yaml` — builds each service image and pushes to ECR.

## Constraints
- Trigger: push to main OR workflow_dispatch.
- Matrix: web-ui, api, worker, otel-gateway, loki, tempo, grafana, alertmanager, blackbox.
- OIDC assume gh-deploy-dev-role. docker buildx with `cache-to type=gha`.
- Multi-arch (amd64+arm64) for services; amd64 for the observability stack.
- Tags: short git SHA AND branch AND semver from CHANGELOG (release).
- cosign signing (recommended). Trivy scan AFTER push; fail on HIGH/CRITICAL unless suppressed
  with reason.
- Emit EventBridge event `images.built` with SHA + services for the deploy workflow.

## Acceptance
A commit to main produces new tagged images in ECR within 15 minutes.

## Enhancements (v2.1)
- Observability images are **pinned upstream digests re-tagged/mirrored into ECR**, not rebuilt —
  don't maintain your own Loki build. The matrix distinguishes `build:` vs `mirror:` entries.
- Scan-before-use ordering fixed: push to a `-candidate` tag, scan, then re-tag to the deployable
  tag on pass — "scan after push" must not leave a vulnerable tag deployable in the gap.
- SBOM (syft) generated and attached to the image as an attestation alongside the cosign signature.
