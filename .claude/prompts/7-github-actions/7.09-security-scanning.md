# Prompt: Security Scanning

## Goal
Produce `.github/workflows/security.yaml` — periodic and event-driven scans.

## Constraints
- Trigger: daily + push to main.
- Jobs: trivy-images (ECR CVEs); trivy-fs (secrets); dep-review; codeql (Java, Python,
  JavaScript); iam-access-analyzer (unintended public/cross-account access); cfn-nag-strict (weekly).
- SARIF to GitHub Security tab. Critical findings → GitHub issues with severity label + Slack.

## Acceptance
A test vulnerable dependency is flagged within 24 hours.

## Enhancements (v2.1)
- Findings deduplicated by fingerprint before issue creation — daily scans re-filing the same CVE
  as new issues trains everyone to ignore them.
- Suppressions live in a reviewed file (`.security/suppressions.yaml`) with owner + expiry date;
  expired suppressions fail the scan.
- Add `gitleaks` history scan monthly (trivy fs catches the working tree; leaked-then-deleted
  secrets live in history).
