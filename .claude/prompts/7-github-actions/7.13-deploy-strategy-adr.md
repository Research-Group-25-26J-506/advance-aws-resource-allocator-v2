# Prompt: Deployment Strategy Decision

## Goal
Document the decision: rolling deployment for MVP, ECS Blue/Green via CodeDeploy for Phase 5.

## Constraints
- Rolling: default, simple, ECS-native, no CodeDeploy dependency, circuit breaker.
- Blue/Green: CodeDeploy application + deployment group; two target groups per service;
  auto-rollback on alarm.
- Rolling is fine for an internal platform; Blue/Green when SLA ≥ 99.9%.
- ADR compares tradeoffs, states the current choice, and lists revision triggers.

## Outputs
`docs/decisions/ADR-011-ecs-deploy-strategy.md`.

## Acceptance
A new engineer understands the choice in 5 minutes.

## Enhancements (v2.1)
- Add the third option to the comparison (ECS native blue/green target-group swap and
  weighted-target canary via ALB) — the space isn't binary, and the ADR should show it was considered.
- Revision triggers are measurable ("p99 user-visible deploy error rate > X", "SLA commitment
  signed"), not vibes.
