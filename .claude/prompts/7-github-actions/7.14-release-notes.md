# Prompt: Release Notes Automation

## Goal
Produce `.github/workflows/release-notes.yaml` — auto-generate release notes on tag push.

## Constraints
- Trigger: push tag v*. release-drafter accumulates PR labels into categorized notes.
- Label-driven sections: feature, bugfix, breaking-change, deprecation, docs, security.
- Publishes GitHub Release + Slack #platform-announcements. Includes deploy status link +
  dashboard snapshot.

## Acceptance
Tagging v1.2.0 produces a grouped release page with no manual editing.

## Enhancements (v2.1)
- A required PR check enforces that every PR carries exactly one release label — release-drafter
  output is only as good as labeling discipline.
- `breaking-change` entries require a migration-note section in the PR body; the workflow copies
  it into the release verbatim.
