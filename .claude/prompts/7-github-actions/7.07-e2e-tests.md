# Prompt: E2E Test Workflow

## Goal
Produce `.github/workflows/e2e.yaml` — Playwright E2E against a deployed environment.

## Constraints
- Called by deploy workflow after successful compute deploy to dev/stg.
- Points at the deployed URL. Test accounts pre-provisioned in Cognito (dev only).
- Tests: catalog rendering, S3 bucket end-to-end, request lifecycle, approval flow (mock in dev),
  sync preview.
- Cleans up created resources via the platform's delete API. HTML report artifact.
- Failure blocks promotion to the next environment.

## Acceptance
E2E green in dev before stg deploy starts. Failed E2E notifies (Slack; page only if blocking prod).

## Enhancements (v2.1)
- Cleanup runs in an `always()` finalizer AND a nightly janitor sweeps orphaned
  `e2e-*`-prefixed resources — flaky-test debris in a real AWS account compounds fast.
- Test data namespaced per run (`e2e-{run_id}-…`) so concurrent runs can't collide.
- The "real provisioning" test asserts final CFN stack tags include PlatformRequestId — the tag
  policy gets continuously verified end to end.
