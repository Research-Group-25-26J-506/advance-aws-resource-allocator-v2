# Prompt: Repo Conventions and Protection

## Goal
Configure the platform repo with the right hygiene: branch protection, CODEOWNERS, commit conventions.

## Constraints
- `.github/CODEOWNERS` with per-directory owners (platform-team → infrastructure/, backend-team →
  backend/, etc.).
- Branch protection on main: require PR; required checks (lint, test, cfn-lint, cfn-nag);
  CODEOWNERS review; dismiss stale approvals; linear history.
- Conventional Commits via commitlint action. SECURITY.md + CONTRIBUTING.md.
- `.github/pull_request_template.md` with checklist (tests, docs, ADR needed?).
- Signed commits required.
- Actions permissions: read+write GITHUB_TOKEN only; third-party actions only from **pinned SHAs**.

## Acceptance
Direct push to main is rejected. A PR without a passing test check cannot merge.

## Enhancements (v2.1)
- Protection expressed as code (Terraform github provider or `gh api` bootstrap script committed
  to the repo) — clickops branch protection is unauditable and unportable.
- Default workflow permissions set to `contents: read` at the repo level; jobs escalate explicitly.
- An `actionlint` + `zizmor` (Actions security linter) pre-commit hook mirrors CI.
