# Prompt: Dependabot

## Goal
Produce `.github/dependabot.yaml`.

## Constraints
- Ecosystems: npm (frontend), gradle (backend), pip (lambdas), docker, github-actions.
- Weekly, Monday morning. Grouped updates (all Cloudscape together, all Spring Boot together).
- Auto-merge patch versions of test deps if CI passes. Reviewers per ecosystem (CODEOWNERS).

## Acceptance
Every Monday shows Dependabot PRs, grouped sensibly.

## Enhancements (v2.1)
- github-actions ecosystem updates keep SHA pins (Dependabot updates the pinned SHA + version
  comment) — consistent with 7.1's pinning rule.
- Auto-merge implemented via a dedicated workflow that checks `metadata.update-type ==
  version-update:semver-patch` AND the dependency is in an allow-list — never blanket auto-merge.
