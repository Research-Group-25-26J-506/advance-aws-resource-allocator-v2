# Prompt: Observability Infrastructure

## Goal
Produce `infrastructure/observability/*.yaml` provisioning the full observability platform.

## Constraints
- All resources tagged Component=observability.
- Cross-stack references via **SSM Parameter Store** (not Exports — deletion pain).
- Each service exposes /metrics for self-scrape.
- Recording/alert rules deployed via `aws amp put-*` in a post-deploy step (not native CFN).
- Grafana dashboards provisioned via file mount from S3.

## Outputs
amp.yaml, otel-gateway.yaml, loki.yaml, tempo.yaml, grafana.yaml (AMG or ECS), alertmanager.yaml,
blackbox.yaml, k6.yaml.

## Acceptance
Full stack deploys cleanly. First metric ingest measurable within 5 minutes.

## Enhancements (v2.1)
- Deploy-order manifest committed (`observability/DEPLOY_ORDER.md`): amp → loki/tempo →
  otel-gateway → grafana → alertmanager → blackbox/k6 — the gateway config references endpoints
  that must exist.
- `ObservabilityProfile` parameter: dev-lite (1 task each, no NLB where an internal ALB/CloudMap
  suffices) vs full — mirrors the platform-wide cost switches.
- The post-deploy `amp put-*` step is a versioned script in the repo, executed by the 7.5 deploy
  workflow, never by hand.
