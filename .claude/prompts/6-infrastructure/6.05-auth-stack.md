# Prompt: Auth Stack (Cognito)

## Goal
Produce `infrastructure/platform/auth.yaml` — Cognito user pool and app clients.

## Constraints
- User pool platform-users, MFA optional (SOFTWARE_TOKEN_MFA), password policy ≥ 12 chars.
- App client web-app: PKCE + authorization_code. Callback URLs configurable per env.
- App client api-server: M2M testing only.
- Custom attributes: team_id, cost_center. Groups: PLATFORM_ADMIN, TEMPLATE_ADMIN, APPROVER, USER.
- Cognito domain `platform-auth-{account}-{env}`. Hosted UI branded via helper Lambda.

## Acceptance
Signing up and logging in yields a JWT with the correct groups claim.

## Enhancements (v2.1)
- Advanced security features (compromised-credential detection) ENFORCED in prod, AUDIT in dev.
- Token lifetimes pinned: access 60 min, id 60 min, refresh 12 h (web client) — and the web app
  uses refresh-token rotation.
- Self-signup disabled; users provisioned by admin API/SCIM — this is an internal platform.
- A third app client `system-sync` (client-credentials) for the 7.8 sync-trigger workflow, scoped
  to a dedicated resource-server scope `sync:trigger` rather than impersonating a human user.
