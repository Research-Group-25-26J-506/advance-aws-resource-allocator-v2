# Prompt: Compute Tier Stack

## Goal
Produce `infrastructure/platform/compute.yaml` — ECS cluster, services, ALB.

## Constraints
- ECS cluster platform-cluster (Fargate providers, Container Insights).
- ALB internet-facing with WAF association.
- Services: web-ui, api, worker. Task def per service: main container + OTel Collector sidecar +
  Fluent Bit sidecar. Fluent Bit → OTel gateway, NOT CloudWatch.
- OTel sidecar config from SSM `/platform/otel/sidecar/config`.
- Task + execution roles per service. Auto-scaling: CPU 60%; api/web-ui min 2 max 10;
  worker min 3 max 20.
- Target groups: web-ui (`/`), api (`/api/*`). Health checks `/actuator/health/readiness`.
- Deployment controller ECS rolling; circuit breaker enabled.
- Outputs: ALB DNS, target group ARNs.

## Acceptance
ALB DNS returns 200 for /healthz per service path. Rolling deploy picks up a new image tag without
downtime.

## Enhancements (v2.1)
- **ALB idle timeout ≥ 120 s + SSE keepalive comments** — the SSE endpoints (2.5/2.10) silently
  die at the 60 s default; pair with a 15 s server-side keepalive event.
- `Scale` parameter (dev: min 1 everywhere; prod: the stated minimums) — same cost rationale as
  6.2/6.3.
- ECS Exec enabled in dev only (audited via CloudTrail), disabled in prod.
- WAF: AWS managed core rule set + rate-based rule on `/api/*`; WebACL ARN read from SSM so the
  WAF stack can evolve independently.
