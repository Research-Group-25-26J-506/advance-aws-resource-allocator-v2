# Prompt: Sync Migration Playbook

## Goal
Produce `docs/runbooks/sync-migration.md` — moving from hand-uploaded S3 templates to the sync
workflow.

## Constraints
Steps:
1. Create platform-templates repo.
2. Commit existing S3 templates to the repo, preserving directory structure.
3. Run sync in DRY_RUN — expect all UNCHANGED.
4. Run real sync — expect quick completion.
5. Revoke direct S3 write on the templates bucket except the sync worker role.
6. Add the sync CI check on the templates repo.

Rollback: if step 3 shows unexpected diffs, investigate before proceeding.
Include exact aws cli commands and expected outputs.

## Acceptance
Following the playbook in a sandbox produces a clean transition with no downtime.

## Enhancements (v2.1)
- Step 2 gains a checksum manifest step (`sha256sum` per object, committed) so step 3's
  "UNCHANGED" claim is verifiable byte-for-byte, not just by version string.
- Step 5 is expressed as the bucket-policy change (10.x quickstart already ships this posture for
  fresh accounts) — migration and greenfield converge on the same end state.
