# Prompt: platform-templates Repo Scaffold

## Goal
Produce the initial file structure and CI workflows for the platform-templates repository.

## Constraints
- `templates/{template_id}/v{semver}/` with template.yaml, schema.json, manifest.json, CHANGELOG.md.
- `docs/authoring-guide.md` documenting the manifest schema, version semantics, validation stages.
- `scripts/local-validate.sh`: run the same 8-stage validator locally against one template version.
- `validate.yaml` (PR): cfn-lint, cfn-nag (strict), JSON Schema syntax, manifest schema;
  comment PR with results.
- `release.yaml` (tag v*): verifies no unpublished version was modified since last release, calls
  the platform's sync API in DRY_RUN mode, comments the summary on the tag.
- README with contribution guidelines and version semantics (major/minor/patch).

## Outputs
Repo layout with `templates/`, `docs/`, `scripts/`, `.github/workflows/` and the two workflows.

## Acceptance
`scripts/local-validate.sh` on `s3-bucket/v1.0.0` passes after clone. A PR triggers validate.yaml
with useful comments.

## Enhancements (v2.1)
- An **immutability CI check in the repo itself**: PR fails if it modifies any
  `templates/*/v*/` path that already exists on main (git diff against merge-base) — catches
  violations before they ever reach the platform's sync preview.
- CODEOWNERS: each template folder owned by its owning team; platform-team owns docs/ and scripts/.
- Starter set committed: `s3-bucket/v1.0.0` fully worked, so the quickstart seed sync (10.x) has
  something real to publish.
