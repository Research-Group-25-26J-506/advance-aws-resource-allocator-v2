# Prompt: SyncController Wire-up

> Endpoint contracts live in 3.2 (OpenAPI). This prompt implements the Spring Boot controllers.

## Goal
Implement `backend/api/.../controller/SyncController` with the sync endpoints and DTOs.

## Constraints
- `@RestController` at `/api/v1/admin/templates/sync`; `@PreAuthorize("hasRole('PLATFORM_ADMIN')")`
  on the class.
- `POST /`: create sync request, insert template_syncs row, publish to SQS, return 202 + Location.
- `GET /`: paginated list. `GET /{id}`: detail. `GET /{id}/events`: SSE stream of sync_events.
- `GET /preview?commit_sha=X`: **synchronous** dry-run — up to 30 s. Do NOT enqueue; run inline on
  a bounded thread pool.
- All requests carry Idempotency-Key. DTOs are Java records with @Schema annotations.

## Acceptance
`curl` POST creates a sync visible via GET. SSE stream shows validation stage events in real time.

## Enhancements (v2.1)
- Preview results cached (Caffeine) keyed by commit_sha, TTL 10 min — the modal (2.9) shows
  "computed N min ago"; repeated previews of the same SHA are free.
- Preview thread pool bounded (e.g. 2) with a fast 429 + Retry-After when saturated, and an
  end-to-end timeout of 60 s — a synchronous 30 s endpoint must never pile up.
- SSE endpoint replays persisted sync_events from `Last-Event-ID` before streaming live ones.
