# Prompt: PlatformStatus (typed StatusIndicator wrapper)

## Goal
Build `PlatformStatus.tsx` — a typed wrapper mapping every possible request/sync status to the
correct Cloudscape `StatusIndicator` type.

## Constraints
- Type-safe exhaustive union of every status: DRAFT, PENDING_VALIDATION, FAILED_VALIDATION,
  PENDING_APPROVAL, REJECTED, QUEUED, CREATE_IN_PROGRESS, CREATE_COMPLETE, CREATE_FAILED,
  ROLLBACK_IN_PROGRESS, ROLLBACK_COMPLETE, ROLLBACK_FAILED, UPDATE_IN_PROGRESS, UPDATE_COMPLETE,
  UPDATE_FAILED, UPDATE_ROLLBACK_IN_PROGRESS, UPDATE_ROLLBACK_COMPLETE, DELETE_IN_PROGRESS,
  DELETE_COMPLETE, DELETE_FAILED.
- Sync-specific: SYNC_PENDING, SYNC_VALIDATING, SYNC_UPLOADING, SYNC_COMPLETE, SYNC_FAILED.
- Mapping: PENDING → `pending`; `*_IN_PROGRESS` → `in-progress`; COMPLETE/SUCCESS → `success`;
  FAILED/REJECTED → `error`; ROLLBACK_IN_PROGRESS → `warning`; DELETE_COMPLETE → `stopped`.
- Never-check default branch for exhaustiveness. Export all types.

## Acceptance
TypeScript compilation fails if a new status is added but not mapped.

## Enhancements (v2.1)
- Status unions generated from `openapi.yaml` enums (single source of truth) rather than hand-typed.
- Also export `isTerminal(status)` and `isInProgress(status)` helpers — pages currently
  reimplement `LIKE '%_IN_PROGRESS'` logic ad hoc.
- Human label map included (CREATE_IN_PROGRESS → "Creating…") for consistent copy everywhere.
