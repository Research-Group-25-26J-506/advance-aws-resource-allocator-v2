# Prompt: Request Detail Page

## Context
Post-submission destination. Shows lifecycle with live updates.

## Goal
Produce `RequestDetailPage.tsx` with real-time status.

## Inputs
- `GET /api/v1/requests/:id`
- `GET /api/v1/requests/:id/events` (SSE stream)
- `GET /api/v1/requests/:id/outputs`
- `POST /api/v1/requests/:id/retry`, `/cancel`, `DELETE /api/v1/requests/:id`

## Constraints
- Header: `Request {shortId}` with `ButtonDropdown`: Retry (if FAILED), Update parameters (if
  COMPLETE), Delete (with `Modal` confirmation), View in AWS Console.
- Row 1 (`ColumnLayout` 4): Template (with version), Environment (Badge), Region, Owner.
- Row 2: large `StatusIndicator` + `ProgressBar` indeterminate when `*_IN_PROGRESS`.
- Tabs: Overview, Parameters, Events, Logs, Approvals (if applicable), Trace.
- Overview: `KeyValuePairs` of outputs (ARN, URL), tags, cost estimate, AWS Console link.
- Events: vertical timeline from `GET /events`. Each item: timestamp, from→to, reason, source
  (Platform vs CFN). `ExpandableSection` for full reason.
- Logs: embedded Grafana Loki panel filtered to `request_id` (iframe with signed URL).
- Trace: embedded Grafana Tempo panel showing the full distributed trace.
- Auto-refresh 5s while status matches `%_IN_PROGRESS`; stop on terminal state. SSE preferred.
- State transitions push a `Flashbar` item (auto-dismiss). Failed states show dismissible `Alert`
  with CFN reason + Retry button.

## Acceptance
A full lifecycle renders correctly with all events visible. Trace tab shows spans
UI → API → SQS → Worker → CFN.

## Enhancements (v2.1)
- SSE with automatic fallback to 5s polling on connection failure (and exponential backoff on
  reconnect) — note ALB idle timeout must exceed SSE keepalive interval (see 6.4).
- Tabs deep-linkable: `/requests/:id?tab=events`.
- Delete confirmation modal requires typing the resource name (Cloudscape delete pattern) —
  destructive actions on real AWS resources deserve friction.
- Events list virtualised beyond 200 items; CFN reasons can be long.
