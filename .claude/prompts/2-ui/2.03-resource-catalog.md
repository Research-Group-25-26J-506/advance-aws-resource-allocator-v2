# Prompt: Resource Catalog

## Context
Users browse available resource templates and pick one to launch a new request.

## Goal
Produce `CatalogPage.tsx` as a card-grid catalog with filtering, search, and category navigation.

## Inputs
- `GET /api/v1/templates?maturity=stable,beta` → `{ id, name, description, category, maturity, latest_version, icon_key }[]`.

## Constraints
- Header: "Resource catalog". Button "Request a new template".
- Left panel: category filter (Storage, Compute, Database, Networking, Integration, Security,
  Monitoring, plus "All").
- Top toolbar: `TextFilter` + `PropertyFilter` (Stable, Beta, Recommended).
- Cards layout: 4/3/2/1 columns responsive. Card content: AWS service icon (top-left, 32px), name,
  one-line description, Badges (Category, Maturity, latest version), tertiary link "View details".
- Click card → `/catalog/:templateId`.
- Combined filters compose (category AND text AND maturity). Empty result state offers "Clear filters".

## Acceptance
Filtering by category and searching text simultaneously narrows the result set. Empty state offers a clear-filters button.

## Enhancements (v2.1)
- Filter state round-trips through URL query params so catalog views are shareable/bookmarkable.
- `icon_key` → icon lookup has a guaranteed fallback glyph; unknown keys never break the card.
- Full keyboard navigation: cards are focusable, Enter opens details.
- Client caches the template list for 5 min (stale-while-revalidate) — the catalog is read-heavy.
