# Prompt: Dynamic Resource Creation Wizard

## Context
The most important screen. Renders dynamically from a template's JSON Schema so **one component
covers every template**.

## Goal
Produce `CreateResourceWizard.tsx` as a Cloudscape `Wizard` with 4 steps.

## Inputs
- Props: `template = { id, name, version, description, schema (JSONSchema7), estimated_cost }`;
  `onSubmit(payload) → Promise<{ request_id }>`.
- `GET /api/v1/regions?env` → allowed region list.
- `GET /api/v1/teams/me` → `cost_center` for default tag values.

## Constraints
- **Step 1 "Basics":** name, environment (`Select`; PROD shows approval `Alert`), region
  (`Select` from allowlist), description (optional).
- **Step 2 "Configuration":** render dynamically from `template.schema`. Strings→`Input`,
  enums→`Select`, booleans→`Toggle`, integers→numeric with min/max, array of objects→`AttributeEditor`.
  Group by `x-group` annotation.
- **Step 3 "Tags":** mandatory tags (Owner, CostCenter, Environment, Application) prefilled and
  read-only where derived; additional tags via `TagEditor`.
- **Step 4 "Review and submit":** `KeyValuePairs` by section, estimated cost callout, read-only
  `CodeEditor` showing final CFN parameter JSON, confirmation checkbox
  "I understand this will provision real AWS resources".
- Client-side validation with **Ajv** against `template.schema`. Errors inline AND in top `Flashbar`.
- Submit disabled until required fields valid AND checkbox ticked.
- `Idempotency-Key` header = client-generated UUIDv7.
- Schema `x-help` → `HelpPanel` content when field focused.
- State persisted to `sessionStorage` between step changes (survives accidental refresh).

## Acceptance
Rendering three different schemas (S3, RDS, Lambda) produces three coherent working forms with
**no code changes**.

## Enhancements (v2.1)
- Supported JSON Schema subset is explicit: draft-07, no external `$ref` resolution (reject
  templates that need it at validation time, 3.12 stage 2) — prevents a schema fetching arbitrary URLs.
- Ajv error → field mapping table (instancePath → Cloudscape `errorText`) implemented once, unit-tested.
- sessionStorage draft key includes `templateId@version`; a version bump invalidates stale drafts.
- UUIDv7 via a pinned lib (e.g. `uuidv7`), generated once per wizard mount — retries reuse the same key.
- Secret-like fields (`"format": "password"` / `x-sensitive: true`) render masked and are excluded
  from the Step 4 JSON preview.
