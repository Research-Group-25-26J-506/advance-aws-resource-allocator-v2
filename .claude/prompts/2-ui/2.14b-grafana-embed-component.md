# Prompt: GrafanaEmbed Component

## Goal
Build `GrafanaEmbed.tsx` that renders a Grafana panel or dashboard as an iframe with a signed URL
and theme sync.

## Inputs
- Props: `dashboardUid`, `panelId` (optional; omitted = full dashboard), `variables`
  (record of name→value), `height`, `timeRange`.
- `GET /api/v1/observability/grafana/signed-url` → short-lived signed embed URL.

## Constraints
- Fetches the signed URL on mount; retry on 401.
- Passes current app theme (light/dark) via `?theme=` on the iframe URL.
- Loading `Skeleton` state. Refresh interval prop (default off).
- No third-party cookies expected — the signed URL carries auth.

## Acceptance
Embedded panel renders in the same theme as the app and refreshes on interval.

## Enhancements (v2.1)
- Signed-URL response includes `expires_at`; the component re-fetches ~60 s before expiry instead
  of waiting for a 401 flash.
- iframe gets `sandbox="allow-scripts allow-same-origin"` and `referrerPolicy="no-referrer"`.
- Variables and timeRange changes update the iframe URL without full remount (preserve scroll).
