# Prompt: Audit Log

## Context
Compliance and platform engineering need a queryable record of every action.

## Goal
Produce `AuditLogPage.tsx` — power-user query view.

## Inputs
- `GET /api/v1/audit?filters` → paginated results.

## Constraints
- Top: Cloudscape `PropertyFilter` with tokens for Actor, Action, Entity type, Entity ID,
  Environment, Date range.
- Main: Cloudscape `Table` with virtual scrolling. Columns: Timestamp, Actor, Action, Entity,
  Environment, IP address, Source (UI/API/System), Outcome `StatusIndicator`.
- Row click: `ExpandableSection` with full JSON payload in read-only `CodeEditor`.
- Top-right `ButtonDropdown`: "Export to CSV" (client-side), "Export to S3" (server-side; signed URL).
- URL query params round-trip filters (shareable).

## Acceptance
100k+ rows scroll smoothly. Filters compose. Export respects the active filter.

## Enhancements (v2.1)
- Pagination is strictly cursor-based (matches 3.2); "Export to CSV" client-side is capped at the
  loaded page set with a notice — full exports always go server-side to S3.
- The JSON payload viewer redacts fields the server marks `redacted:true` (defense in depth —
  server must already redact secrets before storage).
- Date-range filter defaults to last 7 days to avoid accidental unbounded scans.
