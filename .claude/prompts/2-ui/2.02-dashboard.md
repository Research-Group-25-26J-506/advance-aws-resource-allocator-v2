# Prompt: Dashboard (landing page)

## Context
Landing page after login. Shows recent activity, system health snapshot, and quick actions.

## Goal
Produce `DashboardPage.tsx` (Cloudscape).

## Inputs
- `GET /api/v1/requests?requester=me&limit=10` → recent user requests.
- `GET /api/v1/dashboards/kpis` → `{ active_requests, successful_30d, failed_30d, avg_completion_seconds }` with deltas.
- `GET /api/v1/environments/health` → per-env health.
- `GET /api/v1/templates/recent` → recently published template versions.

## Constraints
- Header: `Welcome back, {firstName}`. Buttons: "Provision a resource" → `/catalog`, "Deploy a service" → `/deploy`.
- Row 1 (`ColumnLayout` 4): four KPI cards with mini sparkline (Cloudscape `LineChart` tiny variant).
- Row 2: "My recent requests" table — Request ID, Resource, Environment, Region, Status
  (`StatusIndicator`), Submitted (relative), Owner. Text filter + column preferences.
- Row 3 (`ColumnLayout` 2): "Environment health" (DEV/STG/PROD rows with `StatusIndicator` +
  last-incident timestamp) + "What's new" (template version list with `New` Badge).
- Empty state: table shows "Browse the catalog" CTA. Loading: skeleton per container.
  Error: top `Flashbar` with retry.

## Acceptance
Renders in both themes and both densities from 1024px up. Sparklines fit inside cards without overflow.

## Enhancements (v2.1)
- KPI delta contract pinned down: API returns `{ value, delta_pct, direction }`; UI never computes deltas.
- Each container fetches independently (parallel) — one failing widget must not blank the page.
- Poll `environments/health` every 60s with `aria-live="polite"` on status changes for accessibility.
- Deep links: clicking a KPI card navigates to the pre-filtered requests list it summarises.
