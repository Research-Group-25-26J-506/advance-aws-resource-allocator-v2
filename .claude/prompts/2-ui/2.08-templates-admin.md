# Prompt: Templates Admin — with Git Sync Banner

## Context
Platform engineers publish new template versions AND trigger Git sync from here.

## Goal
Produce `TemplatesAdminPage.tsx` and `TemplateEditorPage.tsx`.

## Inputs
- `GET /api/v1/templates` → all templates with status, version count.
- `GET /api/v1/admin/templates/sync/latest` → `{ commit_sha, actor, when, status }`.
- `GET /api/v1/admin/templates/sync/head` → `{ current_head_sha, commits_behind }`.

## Constraints
- Page top: **Sync banner** `Container`:
  - Line 1: `Repository: org/platform-templates (main branch)`.
  - Line 2: `Last synced: {when} by {actor} • commit {short_sha} • {status}`.
  - Line 3: `Current HEAD: {short_sha} • {commits_behind} new commits ahead` (or "up to date").
  - Buttons: "Preview changes" (secondary) and "Sync now" (primary).
- Below: templates table — Name, Category, Latest version, Status Badge
  (DRAFT/PUBLISHED/DEPRECATED), Total requests, Last updated, Owner team. Row click → `/templates/:id`.
- `TemplateEditorPage`: two-pane Cloudscape `CodeEditor` for CFN YAML + JSON Schema; tabs above
  each pane for {CFN body, Schema, Manifest}. Toolbar: Validate, Lint (cfn-lint), Preview form
  (`Modal` with dynamic form from current schema), Save draft, Publish version. Bottom `Drawer`
  with validation output, lint results, dry-run changeset preview.
- `PLATFORM_ADMIN` role required for the whole page.

## Acceptance
Publishing a new version creates an immutable `template_versions` row. Previously-created requests
still reference their original version.

## Enhancements (v2.1)
- "Sync now" is disabled while a sync is inflight (`GET /sync?status=running`), with a link to the
  running sync — pairs with the distributed lock (3.10) instead of surfacing a raw lock error.
- Sync banner polls `sync/head` every 60s; `commits_behind > 0` shows an info Badge on the nav item.
- Editor warns on unsaved changes before navigation (route blocker).
- Draft edits in the editor are for DRAFT versions only; PUBLISHED versions open read-only with a
  "create new version" CTA — immutability enforced in the UI as well as the API.
