# Cloudscape Global Design Context

Paste once per UI generation session before any screen prompt.

## Constraints
- Build all UI in **React 18 + TypeScript** using **AWS Cloudscape Design System**.
- Required dependencies: `@cloudscape-design/components`, `@cloudscape-design/global-styles`,
  `@cloudscape-design/collection-hooks`, `react-router-dom`, `ajv` (JSON Schema validation),
  `oidc-client-ts` (Cognito auth), `@opentelemetry/sdk-trace-web`,
  `@opentelemetry/exporter-trace-otlp-http`, `@opentelemetry/instrumentation-fetch`.
- Top-level layout: Cloudscape `AppLayout` with `TopNavigation`, `SideNavigation`, breadcrumbs,
  `HelpPanel` (tools slot), `Flashbar`.
- SideNavigation items: Dashboard · Catalog · My Requests · Deployments · Approvals (approver role
  only) · Templates (admin only) · Sync history (admin only) · Observability (external link to
  Grafana) · Runbooks · Audit Log · Settings.

## Strict design rules
- Use Cloudscape components. Do **not** invent custom equivalents.
- `StatusIndicator` for all state, with correct type per state (see PlatformStatus component, 2.14a).
- Support light + dark and compact + comfortable density (Cloudscape built-in).
- Cloudscape spacing tokens only; no hand-rolled margins.
- AWS Architecture Icons for service badges on resource cards.
- Forms show inline errors + summary `Alert` on submit.
- Auto-inject W3C `traceparent` on every fetch.
- Mock API at `/api/v1` for offline dev.

## Enhancements (v2.1)
- Route-level code splitting (`React.lazy`) per page; suspense fallback uses Cloudscape `Spinner`.
- Central typed API client generated from `openapi.yaml` (3.2) — no hand-written fetch shapes.
- Role gating implemented once in a `<RequireRole>` wrapper reading Cognito groups from the JWT;
  nav items and routes both use it (never hide-only in nav).
- All timestamps rendered in user-local time with UTC tooltip; relative times via a single helper.
