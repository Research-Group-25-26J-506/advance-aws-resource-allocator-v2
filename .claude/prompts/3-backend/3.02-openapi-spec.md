# Prompt: OpenAPI 3.1 Specification

## Goal
Produce `backend/api/src/main/resources/openapi.yaml` — the complete OpenAPI 3.1 spec for the
platform API.

## Constraints
Resources and operations:
- `POST /api/v1/requests`, `GET /api/v1/requests`, `GET /api/v1/requests/{id}`,
  `GET /api/v1/requests/{id}/events` (SSE), `POST /api/v1/requests/{id}/retry`,
  `POST /api/v1/requests/{id}/cancel`, `DELETE /api/v1/requests/{id}`
- `GET /api/v1/templates`, `GET /api/v1/templates/{id}`,
  `GET /api/v1/templates/{id}/versions/{version}`, `POST /api/v1/templates`,
  `POST /api/v1/templates/{id}/versions`
- `POST /api/v1/admin/templates/sync`, `GET /api/v1/admin/templates/sync`,
  `GET /api/v1/admin/templates/sync/{id}`, `GET /api/v1/admin/templates/sync/{id}/events` (SSE),
  `GET /api/v1/admin/templates/sync/preview`
- `POST /api/v1/approvals/{requestId}/approve`, `/reject`, `GET /api/v1/approvals`
- `GET /api/v1/audit`
- `POST /api/v1/deployments`, `GET /api/v1/deployments/{id}`
- `POST /api/v1/webhooks/github`
- `GET /api/v1/me`, `GET /api/v1/regions?env=X`, `GET /api/v1/environments/health`
- `GET /api/v1/runbooks`, `GET /api/v1/runbooks/{id}`
- `GET /api/v1/observability/health`, `/api/v1/observability/grafana/signed-url`,
  `/api/v1/observability/alerts`

Rules:
- All state-creating POSTs accept an `Idempotency-Key` header (UUIDv7); repeated keys within 24h
  return the original response. All write endpoints return a `Location` header.
- Errors: `application/problem+json` (RFC 9457) with type, title, status, detail, instance, and a
  platform-specific `code` field.
- Pagination: `?limit` + `?cursor`; responses carry `next_cursor`.
- Filtering: RHS-colon syntax (`?status=in:CREATE_IN_PROGRESS,QUEUED&environment=eq:PROD`).
- SSE endpoints use `text/event-stream`; each event is a full status snapshot JSON.
- Examples on every operation. Validation with Spectral in CI.

## Acceptance
Spectral lint clean. openapi-generator produces working client stubs. Every path has an example.

## Enhancements (v2.1)
- `securitySchemes`: Cognito JWT bearer defined once and applied globally; webhook endpoint
  explicitly opts out (its auth is HMAC signature, documented).
- SSE events include an `id:` field so clients can resume with `Last-Event-ID`.
- Rate-limit response headers (`Retry-After`, `X-RateLimit-*`) documented on 429s.
- Enum schemas (`RequestStatus`, `SyncStatus`) defined once in `components` — the frontend
  generates PlatformStatus (2.14a) from them.
