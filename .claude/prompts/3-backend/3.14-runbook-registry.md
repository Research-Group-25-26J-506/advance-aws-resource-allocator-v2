# Prompt: Runbook Registry

## Goal
Build a `RunbookRegistry` that indexes markdown runbooks from the platform-code repo.

## Constraints
- Runbooks in `docs/runbooks/*.md` with frontmatter (title, severity, alerts_covered, owner,
  last_reviewed).
- On startup, load all files, parse frontmatter, populate the runbooks table.
- `GET /api/v1/runbooks` lists with filters; `GET /api/v1/runbooks/{id}` returns rendered HTML + metadata.
- Prometheus alert rules include annotation
  `runbook_url: https://platform.internal/runbooks/{id}`.
- CI check: every alert's runbook_url resolves to an existing runbook file (fail PR otherwise).

## Acceptance
Adding an alert without a runbook fails CI. Runbook UI renders markdown with copyable commands.

## Enhancements (v2.1)
- HTML rendering is server-side **sanitized** (allow-list) — same XSS posture as 2.13.
- Startup load is idempotent upsert keyed by path_in_repo; deleted files are soft-deactivated,
  never hard-deleted (old alerts may still link to them).
- Second CI check: `last_reviewed` older than 180 days emits a warning annotation on the PR.
