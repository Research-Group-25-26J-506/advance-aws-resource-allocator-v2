# Prompt: GitHub Tarball Fetcher

## Goal
Build `GitHubTarballFetcher`: pulls a repo tarball at a commit SHA and extracts it safely.

## Constraints
- Uses GitHubAppClient installation token. Endpoint `GET /repos/{org}/{repo}/tarball/{sha}`.
  Follow redirect.
- Streaming extraction to `/tmp/gh-{uuid}/` using Apache Commons Compress.
- Guards: total size ≤ 50 MiB; file count ≤ 5000; reject any entry with `..` in path, absolute
  path, or symlink.
- Returns `ExtractedRepo` with base_dir and cleanup(); cleanup() removes the temp dir, called in
  finally / AutoCloseable.
- Trace attributes: git.sha, tarball.size_bytes, tarball.file_count.

## Acceptance
Malicious tarball with `../` entry rejected. Oversized tarball rejected. Successful extraction
produces a walkable directory.

## Enhancements (v2.1)
- Size guard enforced on **decompressed** bytes during streaming (zip/tar-bomb defense), not just
  Content-Length; abort mid-stream on breach.
- Also reject hardlinks and device/FIFO entries; canonicalise every resolved path and assert it
  stays under base_dir (belt and braces vs `..` string check).
- Per-file size cap (e.g. 5 MiB) — a single giant template.yaml is always wrong.
- Test fixtures checked in: path-traversal tar, symlink tar, bomb tar.
