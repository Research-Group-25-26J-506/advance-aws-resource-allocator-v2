# Prompt: Teardown Runbook + Script

## Context
A pluggable system must unplug cleanly. Sandbox accounts especially need a one-command teardown
that doesn't leave billing surprises.

## Goal
Produce `docs/runbooks/teardown.md` + `scripts/teardown.sh`.

## Constraints
- Delete order = reverse deploy order: compute → observability → auth → data → network → iam →
  quickstart.
- Pre-flight: refuse to run against prod unless `--i-know-this-is-prod` AND the caller's role is
  in platform-leads; print a resource + cost inventory before asking for confirmation.
- Handle the retained/versioned buckets explicitly: optional `--purge-buckets` empties all
  versions + delete markers, then deletes buckets. Without it, print the retained list.
- Handle stragglers: ENIs from Lambda-in-VPC, undeleted changesets from validator stage 8,
  CloudWatch log groups, orphaned exec-role stacks — enumerate and delete or list.
- Post-run verification: `aws resourcegroupstaggingapi get-resources --tag-filters
  Key=ManagedBy,Values=Platform` must return empty (excluding intentionally retained items).

## Acceptance
Running teardown against a dev account leaves zero `ManagedBy=Platform` resources (or an explicit
retained list), and the next month's bill for that account is ~$0.
