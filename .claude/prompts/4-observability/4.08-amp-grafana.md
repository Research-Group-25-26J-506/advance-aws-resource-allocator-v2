# Prompt: AMP + Grafana

## Goal
Provision an AWS Managed Prometheus workspace per environment, and AWS Managed Grafana or
self-hosted Grafana.

## Constraints
- AMP: one workspace per env (platform-dev/stg/prod), Alertmanager config attached, retention 15 months.
- Grafana option A: AMG with SSO from Cognito. Option B: self-hosted on ECS Fargate behind ALB
  with Cognito auth; config as code.
- Data sources provisioned via file: AMP (SigV4), Loki, Tempo.
- Trace↔log correlation both ways: Tempo derives logs from Loki via trace_id; Loki derived field
  regex `(?P<trace_id>[a-f0-9]{32})`.
- Dashboards provisioned as code (4.10).
- Access: PLATFORM_ADMIN Cognito group → Grafana Admin; others → Viewer.

## Acceptance
Clicking a slow trace in Tempo jumps to its logs in Loki with one click, in the same time range.

## Enhancements (v2.1)
- Embedding requirements from 2.12 codified here: `allow_embedding=true`, cookie SameSite=None;
  Secure, CSP `frame-ancestors` limited to the platform origin, and the signed-URL flow
  (short-lived JWT via Grafana auth proxy or service-account token exchanged by the platform API).
- Decision guidance: AMG if you want zero ops (but no anonymous embedding + per-user pricing);
  self-hosted if the signed-URL embed portal (2.12) is a hard requirement. Record as ADR.
- Grafana admin password/service tokens in Secrets Manager, mounted at task start; never baked
  into images or config files.
