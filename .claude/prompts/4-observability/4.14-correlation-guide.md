# Prompt: Correlation Guide

## Goal
Produce `docs/observability/correlation-guide.md` — how to trace a symptom across services using
logs, traces, and metrics.

## Constraints
Cover four scenarios with concrete LogQL, PromQL, and TraceQL examples plus Grafana screenshots:
1. Slow request submission: metric → trace → logs.
2. Failed provisioning: request_id → request_events table → CFN logs → Tempo trace.
3. Sync failure: sync_id → sync_events → Loki logs.
4. Silent worker: worker_inflight gauge → recent messages → Tempo traces of last successful message.

## Acceptance
A new engineer can debug a slow request in under 5 minutes using only this guide.

## Enhancements (v2.1)
- Every query in the guide is also checked into `observability/queries/` as copy-paste files and
  linked from the relevant runbooks — the guide should never drift from what on-call actually runs.
- Add a fifth scenario: "trace exists but logs missing" (sampling vs Loki label mismatch) — the
  most confusing real-world case for newcomers.
