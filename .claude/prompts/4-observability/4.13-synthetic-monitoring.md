# Prompt: Synthetic Monitoring

## Goal
Set up Blackbox exporter for endpoint probes and k6 for scheduled load tests.

## Constraints
- Blackbox exporter on ECS Fargate. Modules: http_2xx, http_401_expected, tcp_connect.
- Probe targets: platform-ui /healthz, api /healthz, api /api/v1/me (expects 401 without token),
  Grafana /api/health, Loki /ready, Tempo /ready.
- k6 scripts in `observability/k6/`; EventBridge → Fargate task every 15 min (smoke) and daily (load).
- k6 metrics to AMP via prometheus-remote-write output.
- Alert: probe_success == 0 for 5m (page).

## Acceptance
Every endpoint has a probe. k6 metrics visible in Grafana. Simulated outage triggers probe_success alert.

## Enhancements (v2.1)
- Synthetic **user-journey** probe added: k6 smoke logs in with a dev test account and submits a
  no-op DRY_RUN request — /healthz being green while Cognito or SQS is broken is a real gap.
- Probe traffic tagged `source=synthetic` so SLIs can exclude it.
