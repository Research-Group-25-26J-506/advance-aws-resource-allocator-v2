# Prompt: Grafana Dashboards as Code

## Goal
Produce dashboard JSON in `observability/dashboards/*.json` — preferably Grafonnet (.jsonnet)
generating them.

## Constraints
- Eight canonical dashboards: platform-health, request-lifecycle, per-template, per-team,
  approvals, slo-tracker, security-audit, template-sync.
- `$env` template variable on every dashboard; request-lifecycle also takes `$request_id` and
  filters all panels.
- Consistent color scheme; SLO threshold overlays where applicable.
- Deployed via Grafana provisioning (files from S3 or ECS volume). Version-controlled.
  Grafonnet imports pinned.

## Acceptance
grafonnet-lint clean. Dashboards import into a fresh Grafana and render with valid queries.
Modifying a dashboard requires a PR.

## Enhancements (v2.1)
- Stable dashboard **UIDs** committed in code — 2.12's portal cards and alert `dashboard_url`
  annotations reference UIDs, and provisioning must not regenerate them.
- CI job runs `grafana-dashboard-linter` plus a promtool-style query check against a recorded
  metric-name list (from the 4.4 catalogue test) so renamed metrics break the PR, not the dashboard.
