# Prompt: Alertmanager

## Goal
Produce `infrastructure/observability/alertmanager.yaml` + CFN to deploy Alertmanager on ECS.

## Constraints
- Default route → slack-platform-warnings. Routes: severity=page + env=prod → PagerDuty;
  severity=page → slack-platform-pages; severity=warn → slack-platform-warnings;
  severity=info → slack-platform-info.
- Group by [alertname, service, env]; group_wait 30s; group_interval 5m; repeat_interval 4h.
- Receivers pull secrets (PagerDuty key, Slack webhook) from files mounted from Secrets Manager.
- Templates: rich text for PagerDuty (title, description, runbook link, dashboard link);
  markdown for Slack.
- AMP integration: AMP alertmanager points here or uses AMP-native.
- Silences UI: Grafana Alerting UI or alertmanager-webui.

## Acceptance
Test alerts of each severity route correctly. Runbook URL renders as a clickable link in Slack.

## Enhancements (v2.1)
- **Deadman switch:** an always-firing `Watchdog` alert routed to a heartbeat receiver
  (PagerDuty/healthchecks.io); silence in the pipe pages someone — the failure mode of a dead
  Alertmanager is otherwise total silence.
- If self-hosted with >1 replica, run in cluster mode (gossip) or notifications duplicate;
  document the choice.
- Inhibition rules: env-down page inhibits downstream warn alerts from the same env.
