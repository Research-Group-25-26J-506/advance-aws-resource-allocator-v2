# Prompt: Local Dev Environment

## Goal
Produce `dev/docker-compose.yaml` + `dev/README.md` standing up the platform locally.

## Constraints
- Services: mysql (aurora-compatible), localstack (SQS, DynamoDB, S3, Secrets Manager),
  otel-collector (single), loki, tempo, grafana, prometheus.
- Spring Boot `local` profile targets these. Frontend dev script proxies to local backend.
- Cognito mocked via a lightweight OIDC provider or a dev-header bypass.
- Makefile: make up / down / seed / test.

## Acceptance
`make up` under 60 s. `make seed` loads demo templates + users. Full E2E runs against the local stack.

## Enhancements (v2.1)
- The dev-header auth bypass is compiled out of production builds (profile-gated bean + an
  ArchUnit/test assertion it doesn't exist outside `local`) — dev bypasses have a way of shipping.
- Pinned image digests + a `make doctor` target that verifies docker/java/node versions before
  `up` — kills the "works on my machine" onboarding hour.
- CFN "execution" in local mode is a stub driver that fakes stack lifecycles (LocalStack CFN is
  not faithful enough) — documented as a known divergence.
