# Prompt: Onboarding Docs

## Goal
Produce `docs/onboarding.md`.

## Constraints
- Structure: prerequisites, tooling install, first PR walkthrough, code map (module by module),
  run locally, debug production safely (read-only queries), on-call basics.
- Time to first PR: 1 day. Time to first dev deploy: 2 days.
- Includes docker-compose for local Aurora + LocalStack + Loki + Grafana.
- Points to this prompt pack for AI-assisted work.

## Acceptance
A new engineer without prior platform knowledge merges a PR in 2 days.

## Enhancements (v2.1)
- A "golden path" first ticket is pre-created (good-first-issue template) so day-one has a real
  target, not a toy.
- Onboarding doc gets a CI link-checker — dead links in onboarding docs are the most common decay.
