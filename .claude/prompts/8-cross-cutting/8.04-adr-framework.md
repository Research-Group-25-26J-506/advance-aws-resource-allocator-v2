# Prompt: ADR Framework + Starter Set

## Goal
Bootstrap Architecture Decision Records.

## Constraints
- MADR-style template: Context, Decision Drivers, Considered Options, Decision, Consequences.
- Numbered, dated, status (proposed | accepted | superseded).

## Outputs
`docs/decisions/ADR-000-template.md` plus:
ADR-001 learning project vs internal tool positioning; ADR-002 single vs multi-account (Phase 1→4);
ADR-003 Cognito; ADR-004 template author = platform-team for first 3 months; ADR-005 mandatory tag
keys; ADR-006 bootstrap deployment strategy; ADR-007 Datadog vs OSS observability → OSS;
ADR-008 Spring Boot 3 + Java 21; ADR-009 CloudFormation vs CDK vs Terraform → CloudFormation;
ADR-010 idempotency key strategy (UUIDv7 + DynamoDB TTL).
