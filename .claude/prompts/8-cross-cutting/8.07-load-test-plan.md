# Prompt: k6 Load Test Plan

## Goal
Produce `observability/k6/plan.md` and `observability/k6/scenarios/*.js`.

## Constraints
- Scenarios: submit_burst (100 req/s × 5 min), sustained_load (10 req/s × 1 h), sync_concurrent
  (10 admins trigger sync simultaneously — expect 9 locked out).
- Metrics: p50/p95/p99 + error rate. Baselines documented after first successful run.
- CI runs a smoke subset on every PR to main. Full run weekly against staging.

## Acceptance
Baseline established per scenario. Regression detected within one week.

## Enhancements (v2.1)
- Load scenarios run in **DRY_RUN / stub-execution mode** against staging — 100 req/s of real
  CreateStack calls is an AWS-bill and service-quota incident, not a test. The stub path is the
  same one local dev uses (8.6).
- Thresholds encoded in the k6 scripts (`thresholds:`) so a regression fails the run itself, not
  just a human reading Grafana later.
